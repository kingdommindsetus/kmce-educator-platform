# Pegasus — October 2 Launch Contract

Launch target: **October 2, 2026**

The launch is a controlled, evidence-backed KMCE operating-company demonstration. It must not pretend unverified integrations are autonomous.

## Founder Command
The founder view must answer:
1. What came in?
2. What is running?
3. What completed?
4. What failed?
5. What needs approval?
6. What is producing verified leads/appointments/revenue?

## Required launch flow
INPUT/EVENT → PEGASUS ROUTE → AGENT ASSIGNMENT → WORK PRODUCT → IRIS/CONTRACT VERIFICATION → APPROVAL IF REQUIRED → RESULT/EVIDENCE → COMMAND CENTER

## Launch-critical offices
- Simon: executive brief and delegation
- Marie: task/queue operations
- IRIS: execution health/evidence
- Echo: lead/outreach preparation
- Booker: appointment handoff
- Mark/Cammy/Evan/Lucy: campaign pipeline
- Snake: verified KPI display
- Alice: commerce/store status

## Evidence rules
- Never label simulated data as live.
- Never label an integration DONE until an end-to-end transaction succeeds.
- Every completed task records actor, input, action, result, timestamp and evidence reference.
- Failed jobs remain visible.
- Approval-required actions cannot silently execute.

## Oct 2 acceptance gates
- Command Center loads reliably.
- Founder can distinguish running/completed/failed/approval-needed work.
- At least one real workflow completes end-to-end with evidence.
- Agent handoff is visible.
- No unauthorized outbound action occurs.
- Verified metrics are labeled by source/as-of time.
- Legacy NERVS/Eyes/Eve are not presented as canonical product names.
- Secrets/customer documents are not exposed.
